# ragtag

`ragtag` packages RagTag for TAFFISH.

Package identity:

- name: `ragtag`
- command: `taf-ragtag`
- kind: `tool`
- version: `2.1.0-r1`
- license: Apache-2.0
- upstream: https://github.com/malonge/RagTag
- upstream release: `v2.1.0`
- runtime version: `ragtag.py --version` reports `v2.1.0`
- image: `ghcr.io/taffish/ragtag:2.1.0-r1`

## What This App Packages

RagTag is a toolkit for reference-guided genome assembly improvement. It
provides homology-based misassembly correction, assembly scaffolding, assembly
patching, scaffold merging, and utilities for AGP, FASTA, PAF, delta, GFF, and
assembly statistics.

This TAFFISH image installs upstream RagTag `v2.1.0` from the official GitHub
tag and bundles the aligners that RagTag can call for its core workflows:

- `minimap2 2.31-r1302`, the default aligner for correction and scaffolding
- `unimap 0.1-r41`, the optional assembly-to-reference aligner
- `MUMmer4 nucmer 4.0.1`, the default/recommended aligner for patching and an
  optional aligner for correction/scaffolding
- `samtools`, for user BAM/SAM workflows and RagTag's read-validation paths

## Scope

This app supports:

- `ragtag.py correct`
- `ragtag.py scaffold`
- `ragtag.py patch`
- `ragtag.py merge`
- `ragtag.py agp2fa`, `agpcheck`, `asmstats`, `splitasm`, `delta2paf`,
  `paf2delta`, and `updategff`
- direct command-mode access to packaged helper scripts, `minimap2`, `unimap`,
  `nucmer`, MUMmer utilities, and `samtools`

This app does not:

- download or bundle reference genomes, Hi-C data, annotations, or project data
- choose assembly-quality thresholds for a biological project
- replace downstream manual inspection of AGP/FASTA outputs

## Container Contents

- `ragtag.py`: upstream command dispatcher
- `ragtag_correct.py`, `ragtag_scaffold.py`, `ragtag_patch.py`,
  `ragtag_merge.py`: implementation scripts for the main workflows
- `ragtag_agp2fa.py`, `ragtag_agpcheck.py`, `ragtag_asmstats.py`,
  `ragtag_delta2paf.py`, `ragtag_paf2delta.py`, `ragtag_splitasm.py`,
  `ragtag_update_gff.py`: upstream file utilities
- `minimap2`, `unimap`, `nucmer`, `delta-filter`, `show-coords`, and other
  MUMmer4 commands
- `samtools`
- `/opt/ragtag/share/doc/ragtag/`: upstream README
- `/opt/ragtag/share/testdata/upstream-tests/`: upstream test scripts retained
  for reference; smoke uses smaller synthetic fixtures

## Usage

Access upstream help:

```sh
taf-ragtag -- --help
taf-ragtag -- --version
taf-ragtag ragtag.py scaffold --help
```

Scaffold a draft assembly against a reference:

```sh
taf-ragtag ragtag.py scaffold -t 8 ref.fa draft.fa -o scaffold_out
```

Use MUMmer4/nucmer instead of minimap2:

```sh
taf-ragtag ragtag.py scaffold --aligner nucmer ref.fa draft.fa -o nucmer_out
```

Patch a target assembly with query sequence:

```sh
taf-ragtag ragtag.py patch target.fa query.fa -o patch_out
```

Check AGP and rebuild FASTA:

```sh
taf-ragtag ragtag.py agpcheck scaffold_out/ragtag.scaffold.agp
taf-ragtag ragtag.py agp2fa scaffold_out/ragtag.scaffold.agp draft.fa > scaffolds.fa
```

## Command Mode

TAFFISH command mode is enabled. Because RagTag's workflow names such as
`scaffold` and `patch` are subcommands of `ragtag.py`, use:

```sh
taf-ragtag ragtag.py scaffold ref.fa draft.fa -o out
```

Do not write `taf-ragtag scaffold ...`; command mode would look for an
executable named `scaffold` inside the container.

Use `taf-ragtag -- --help` or `taf-ragtag -- --version` for option-leading
calls to the default `ragtag.py` command. Direct helper access is also
available:

```sh
taf-ragtag minimap2 --version
taf-ragtag nucmer -V
taf-ragtag ragtag_asmstats.py draft.fa
```

## Inputs

| Input | Meaning | Notes |
| --- | --- | --- |
| reference or target FASTA | coordinate guide for correction, scaffolding, or patching | may be uncompressed or bgzipped where upstream supports it |
| query FASTA | draft assembly, query assembly, or component sequences | used by correct/scaffold/patch/agp2fa |
| AGP | scaffold structure | used by merge, agpcheck, agp2fa, updategff |
| PAF/delta | alignment exchange formats | generated by minimap2/unimap/nucmer paths and utilities |
| GFF/BAM | optional annotation or Hi-C/read-validation inputs | supplied by the user; not generated by this app |

## Output Notes

RagTag writes each workflow into an output directory, defaulting upstream to
`ragtag_output` unless `-o` is provided. Typical outputs include
`ragtag.scaffold.agp`, `ragtag.scaffold.fasta`, confidence tables, alignment
intermediates, and command-specific logs. Utilities may write to stdout, for
example `agp2fa` and `asmstats`.

## Resources, Databases, and Platform

No external database, network service, GPU, or bundled reference genome is
required at run time. Native container builds are requested for `linux/amd64`
and `linux/arm64`.

CPU, memory, and disk requirements scale with assembly size and aligner choice.
`minimap2` is the default for `correct` and `scaffold`; `nucmer` is the default
for `patch`; `unimap` is available for users who explicitly request it.

## Boundaries

This is a command-line runtime for upstream RagTag and its direct aligner
dependencies. It is not a full genome-assembly curation workflow, does not
retrieve references or annotations, and does not decide which RagTag thresholds
are biologically appropriate for a project. Hi-C merge support expects the user
to provide BAM files prepared outside this app.

## Troubleshooting

- Use explicit subcommands such as `taf-ragtag ragtag.py scaffold ...`; bare
  `taf-ragtag scaffold ...` is not the right command-mode form.
- If a command starts with an option, use `taf-ragtag -- --help` or
  `taf-ragtag -- --version`.
- Existing output directories may cause RagTag to retain intermediate files.
  Use upstream `-w` when you intentionally want to overwrite intermediates.
- Large assemblies can create large PAF/delta/BAM intermediates. Put `-o` on a
  filesystem with enough free space.

## Testing

The smoke test covers:

- RagTag runtime version and help
- help for `scaffold` and `patch`
- presence of the main RagTag scripts and bundled aligners/utilities
- versions for `minimap2`, `unimap`, `nucmer`, and `samtools`
- Python import checks for `ragtag_utilities`, `numpy`, `pysam`, `networkx`,
  and `intervaltree`
- shared-library checks for native aligner/MUMmer executables
- a synthetic `ragtag.py scaffold` run using minimap2
- AGP validation and assembly statistics on the synthetic output
- a synthetic nucmer-backed scaffold path
- a direct unimap PAF path

The smoke test is intentionally small and offline. It does not replace full
scientific validation on production assemblies.
